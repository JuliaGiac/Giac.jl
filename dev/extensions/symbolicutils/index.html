SymbolicUtils.jl: exact conversion

With SymbolicUtils.jl loaded (Symbolics is not needed), to_symbolicutils and to_giac convert between Giac and SymbolicUtils exactly: numbers stay integers and rationals, radicals and constants stay unevaluated terms, and anything without an exact form is an error rather than a float. It was written for MathInterchange's adapter, whose Lean checkers read SymbolicUtils terms.

using Giac, SymbolicUtils
using Giac.Commands: integrate, simplify
@syms x::Real
@giac_var v
names = Dict("v" => x)                       # Giac name => SymbolicUtils symbol

to_symbolicutils(integrate(v^2 + 2, v); symbols = names)   # (1//3)*x^3 + 2x
to_symbolicutils(sqrt(giac_eval("2")) * v; symbols = names) # sqrt(2)*x, never 1.414…*x
to_symbolicutils(assuming(() -> simplify(sqrt(v^2)), v > 0); symbols = names)   # x

to_giac((0 < x) & (x <= 10); names = Dict(x => "v"))       # (v>0) and (10>=v)

symbols maps Giac names to the SymbolicUtils symbols to use (for instance your own fresh names). A name not in it becomes a Real symbol of the same name; with strict_symbols = true it is an ArgumentError instead, for a caller to whom an identifier outside its request means something unexpected came back. With exact = true, the default, a GIAC float or a function outside the elementary ones (such as Gamma) is an ArgumentError; exact = false accepts them.

GIAC evaluates some elementary functions into others before they come back: asinh(v) is ln(v+sqrt(v^2+1)), ceil(v) is -floor(-v); the conversion returns that form, exactly.

To Giac

to_giac(t; names, exact = true) builds the Giac expression node by node. names maps SymbolicUtils symbols to Giac names. Comparisons become Giac relations, and & and | become and and or. In exact mode a float (0.5) or an unknown function is an ArgumentError.

A round trip keeps exactness: to_symbolicutils(to_giac(e; names); symbols) is e for e = (1//3)*x^3 + sqrt(2)*x.

Unevaluated Giac source

to_giac builds the value, and Giac evaluates each node as it is built. Giac.giac_source(t; names, exact = true) writes the Giac source text instead, unevaluated, so a caller can record exactly what Giac receives:

Giac.giac_source((0 < x) & (x <= 10); names = Dict(x => "v"))   # "((0<v) and (v<=10))"
Giac.giac_source(sqrt(x^2); names = Dict(x => "v"))              # "sqrt((v^2))"

Numbers stay exact ((1/3)); comparisons are Giac relations; &, | and ! are and, or and not. A float or an unknown function is an ArgumentError in exact mode. giac_eval(Giac.giac_source(t; names)) gives what to_giac(t; names) builds.
